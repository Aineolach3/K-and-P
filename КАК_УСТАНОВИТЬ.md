# Корзина и плита — Android-приложение

Это готовый проект Android-приложения. Внутри — ваше приложение целиком (работает без интернета),
иконка-логотип, сохранение файлов в «Загрузки», печать меню, камера для фото ценников и кнопка «Назад».

Собрать APK можно двумя способами. Первый не требует установки программ.

---

## Способ 1. Через GitHub — без программ, из браузера (≈10 минут)

1. Зарегистрируйтесь на github.com (бесплатно).
2. Справа вверху «+» → **New repository**. Имя: `korzina`. Можно сделать **Private**. Нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**.
4. Распакуйте архив проекта и **перетащите в окно браузера всё содержимое папки** `korzina-android`
   (папки `app`, `gradle`, файлы `build.gradle`, `settings.gradle`, `gradlew` и остальные). Нажмите **Commit changes**.
5. Скрытая папка `.github` при перетаскивании может не загрузиться. Тогда:
   вкладка **Actions** → **set up a workflow yourself** → удалите текст в окне →
   вставьте содержимое файла `.github/workflows/build-apk.yml` из архива → **Commit changes**.
6. Откройте вкладку **Actions**. Сборка «Собрать APK» запустится сама (≈5–7 минут).
   Если не запустилась — выберите её слева и нажмите **Run workflow**.
7. Когда появится зелёная галочка, откройте сборку и внизу в разделе **Artifacts** скачайте `korzina-i-plita-apk`.
   Внутри zip-архива — файл **korzina-i-plita.apk**.

## Способ 2. Через Android Studio на компьютере

1. Установите Android Studio: developer.android.com/studio.
2. **File → Open** → выберите папку `korzina-android`. Дождитесь окончания синхронизации (внизу полоска прогресса).
3. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. Нажмите **locate** во всплывающем окне — там лежит `app-debug.apk`.
   Можно и сразу запустить на телефоне, подключённом кабелем: зелёная кнопка ▶.

## Установка на телефон

1. Перекиньте APK на телефон (Telegram «Избранное», кабель, Google Диск — как удобно).
2. Откройте файл. Android попросит разрешить установку из этого источника — разрешите.
3. Если появится предупреждение Google Play Protect — «Подробнее» → «Всё равно установить».
   Так бывает со всеми приложениями не из Play Маркета.
4. Требуется Android 10 или новее.

## Обновление

Приложение подписано одним и тем же ключом (`app/korzina.keystore`), поэтому новые версии
ставятся поверх старой, **данные сохраняются**. Чтобы выпустить обновление:
замените `app/src/main/assets/index.html` новой версией, увеличьте `versionCode` в `app/build.gradle`
(1 → 2 → 3…) и соберите заново.

Не теряйте файл `korzina.keystore` — без него обновление поверх установленного приложения не встанет.
Перед любыми экспериментами делайте копию данных: **Настройки → Скачать копию**.

## Где хранятся данные

Покупки, холодильник, рецепты и настройки хранятся внутри приложения на телефоне.
Выгрузки меню, списки и резервные копии сохраняются в **Загрузки / Корзина и плита**.

## Помощник и ИИ

Помощник работает и без интернета — по встроенным правилам. Чтобы он поддерживал живой разговор,
подключите ИИ: **Настройки → Помощник ИИ**.
Рекомендуем **OpenRouter** — бесплатно и работает из России:
openrouter.ai → войти через Google или почту → **Keys → Create key** → вставить ключ в приложение → «Проверить связь».
